# Generated artwork fallback index

Generated by `npm run audit:artwork`. Provider metadata and image URLs, not bundled third-party image bytes. Sources: https://api.tcgdex.net and https://github.com/PokemonTCG/pokemon-tcg-data . The latter dataset is MIT-licensed; original card artwork remains the property of its respective rights holders. Neutral `set-*.svg` identifiers are original E-Binder fallbacks, not official set logos.

`audit.json` records the exact checked scope and unavailable primary sources. Card identities and ownership are never inferred from images. English replacement artwork is visibly labelled. Dynamic card image HTTP failures are handled in the browser; the release audit does not claim to HTTP-probe every card in every worldwide catalogue.
